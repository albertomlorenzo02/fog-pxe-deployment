# FOG PXE Deployment Lab

> Laboratorio de despliegue automatizado de sistemas operativos mediante FOG Project y PXE.

## 📖 Descripción

Este proyecto documenta la implementación de un servidor FOG sobre Ubuntu Server para capturar y desplegar imágenes de sistemas operativos a través de la red utilizando PXE.

El laboratorio fue desarrollado como proyecto final del ciclo ASIR y está completamente virtualizado mediante VirtualBox.

## 🚀 Tecnologías utilizadas

- Ubuntu Server 22.04 LTS
- FOG Project
- VirtualBox
- PXE
- DHCP
- TFTP
- Apache
- PHP
- MySQL
